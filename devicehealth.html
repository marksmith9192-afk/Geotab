Diagnosis Logic

  • Issue-only list: healthy vehicles are intentionally excluded so the dashboard stays focused on the units that need action.
  • Cellular status: based on the most recent communication evidence we can find from the device record plus matching communication-related measurements and faults.
  • GPS status: based on recent log records, GPS-related measurements, and GPS-related fault text. If cellular appears current but GPS is old or missing, the add-in flags that mismatch.
  • Engine status: based on recent trip context, engine-related measurements, and engine or harness fault text.
  • Possible issues: the top diagnosis is chosen from the strongest evidence, but the detail view also shows the other issue candidates that matched.
